dsh-ios-roothide — 安装与部署
================================================================

部署顺序是固定的：**先 web 端（起服务、开放端口），再 cli 端**。
因为 cli 只是前端，端口没开它连不上任何东西。

一次 git clone 两端都在同一个仓库里；装的时候按下面顺序走，
或者直接用第 3 节的 `./install.sh` 一条命令把两端一起装好。


0. 先决条件
----------------------------------------------------------------
  * Node.js >= 18
  * 一个 dsh 安装（提供 dsh web 服务端与 web 前端目录）
  * 该服务的数据目录里有 .launch-token（cli 端认证用）


1. 拉代码（在 newteam 里）
----------------------------------------------------------------
  cd <你的 newteam 目录>
  git clone https://github.com/axisovo/dsh-ios-roothide.git
  cd dsh-ios-roothide

  # 固定版本
  git clone --branch v0.2.0 https://github.com/axisovo/dsh-ios-roothide.git

  拉完先别急着跑 cli —— 下一步先把服务端和 web 端弄起来。


2. 第一步：web 端（起服务 + 开放端口）
----------------------------------------------------------------

  2.1 装 iOS Safari 16 适配层
  ─────────────────────────────
  上游 web 界面是给桌面浏览器构建的，iOS 16 会白屏或输入框错位。
  web/ 就是补齐这一层，另外带一个「⟳ 重启」按钮。

    ./web/install-web.sh <dsh-web-frontend/dist 路径>

    # 例（本机）：
    ./web/install-web.sh \
      ~/.dsh/node_modules/@deepseek-ai/dsh-web-frontend/dist

  脚本会先备份被覆盖的文件为 *.bak-web，再落地：
    - polyfill（iterator / es-late）
    - 键盘 inset 与输入法焦点修复
    - safari16 降级构建（index-safari16-v2.js / vendor-safari16.js）
    - 适配后的 index.html（已注入 restart-button.js）
    - restart-button.js —— 左下角「⟳ 重启」

  2.2 启动 / 重启服务端
  ─────────────────────
    # 方式一：页面左下角的「⟳ 重启」按钮
    # 方式二：命令行
    curl -X POST http://127.0.0.1:3081/dsh-purge/restart \
         -H 'content-type: application/json' -d '{"reason":"install"}'

    # 方式三：直接起进程（没有 purge 插件时）
    dsh web --port 3081

  2.3 开放端口并确认可达
  ─────────────────────
    # 端口必须真的起来，cli 才有得连
    curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3081/

    # 浏览器打开 http://127.0.0.1:3081，iOS 上先强刷一次
    # 看到界面 + 左下角「⟳ 重启」= web 端就绪

  到这里 web 端可以独立使用了。


3. 第二步：cli 端（ds）
----------------------------------------------------------------
  3.1 装依赖（只一个 ws，纯 JS）

    npm install --omit=dev

  3.2 配置并启动

    export DSH_HOME=~/.dsh          # dsh 数据目录，需含 .launch-token
    export DSH_PORT=3081            # 必须与第 2 步开放的端口一致
    node bin/ds.mjs

    # 想直接敲 ds
    npm link
    ds

  3.3 越狱 iOS / 无 JIT 环境（客户端与服务端同机）

    export DSH_WS_MODULE=/path/to/dsh-home/profiles/dsh-tui/node_modules/ws
    <node 路径> --jitless bin/ds.mjs

  注意：cli 端需要在 newteam 中唤起后再使用，
        否则拿不到可用的会话/工具上下文。

  自检（不启动界面）：
    node bin/ds.mjs --version
    node bin/ds.mjs --help


4. 一条命令两端一起装
----------------------------------------------------------------
    ./install.sh                       # 自动找 web 前端目录 → 装适配层 → 重启 → 校验端口 → 装 cli 依赖
    ./install.sh /path/to/dist         # 显式指定 web 前端目录
    ./install.sh --no-restart          # 只装文件，不动正在跑的服务
    ./install.sh --web-only            # 只做 web 端
    ./install.sh --cli-only            # 只做 cli 端

  脚本内部的顺序同样是「web → 校验端口 → cli」，
  端口没起来会明确警告「cli 端会连不上」。


4.5 作为越狱插件安装（.deb，可选）
----------------------------------------------------------------
  不想手工部署的话，可以把两端打成一个 rootless 插件包：

    ./packaging/build-deb.sh
    dpkg -i dist/dsh-ios-roothide_<ver>_iphoneos-arm64.deb

  或者在 Sileo / Filza 里直接点开 .deb 安装。

  装完得到：
    /var/jb/usr/bin/ds                     cli 端（需在 newteam 唤起）
    /var/jb/usr/bin/dsh-ui                 打开本地界面
    /var/jb/Library/LaunchDaemons/…plist   开机自启 web 服务
    /var/jb/etc/dsh-ios-roothide.conf      配置（DSH_ROOT / DSH_PORT / DSH_NODE）
    /var/jb/usr/share/dsh-ios-roothide/    cli 源码 + web 适配层

  前提：设备上已有一份 dsh 安装（提供 node 与 dsh web）。
  装完把 DSH_ROOT 指过去，再重启守护进程：

    launchctl unload /var/jb/Library/LaunchDaemons/com.axisovo.dsh-web.plist
    launchctl load -w /var/jb/Library/LaunchDaemons/com.axisovo.dsh-web.plist

  卸载：dpkg -r com.axisovo.dsh-ios-roothide（prerm 会先停守护进程）

5. 升级
----------------------------------------------------------------
  cd dsh-ios-roothide
  git pull

  ./install.sh --no-restart      # 重装适配层；或只跑 ./web/install-web.sh
  # 重启服务端（按钮 / curl）
  npm install --omit=dev         # 依赖有变时

  页面记得强刷，否则可能还在用缓存的 index.html。


6. 发布新版本（仓库维护者）
----------------------------------------------------------------
  GITHUB_TOKEN=ghp_xxx node scripts/upload.mjs     # 提交并推送
  GITHUB_TOKEN=ghp_xxx node scripts/release.mjs    # 打 tag + 建 Release

  upload.mjs / release.mjs 只用 node:https，不依赖 git 与 curl；
  令牌只从环境变量读，不写入任何文件。


7. 常见问题
----------------------------------------------------------------
  「连接失败：找不到启动令牌」
      DSH_HOME 指错了。确认该目录下存在 .launch-token。

  cli 连不上 / 一直转圈
      端口没开。先确认 http://127.0.0.1:3081 可访问，再启 cli。

  「找不到 ws 模块」
      npm install 没跑，或需要 DSH_WS_MODULE 指到纯 JS 副本。

  iOS 上 node 报 Cannot find module
      node 与 shell 的路径命名空间不同，用 node 可见的绝对路径。

  cli 画面错位 / 重复行
      终端宽度 >= 60 列；< 44 列不画启动横幅的鲸鱼。

  网页上没出现「⟳ 重启」
      index.html 被缓存；Safari 强刷或换无痕窗口。
      确认 dist 下 index.html 含 <script defer src="./restart-button.js">。

  「⟳ 重启」点了显示「未装 purge」
      服务端没装 dsh-purge 插件；用命令行重启代替。
